# extensions — 여기에만 추가합니다

이 폴더는 **여러분이 8주 동안 채우는 곳**입니다. 매주 수업에서 만든 부품을 여기에 옮겨 붙이면, 그게 여러분 브레인의 새 장기가 됩니다.

규칙은 두 줄입니다.

> **① 본체는 건드리지 않습니다.** `scripts/`, `wiki_app/` 은 한 줄도 수정하지 않습니다.
> **② 확장은 여기에 새 파일로만** 추가합니다.

이 규칙은 **여러분에게** 적용됩니다. 본체는 강사가 유지보수하며 버그 수정과 개선이
들어옵니다. 여러분이 본체를 고치면 다음 배포본을 받을 때 그 수정이 사라지고,
무엇이 왜 깨졌는지 아무도 모르게 됩니다. 고치고 싶은 것이 본체에 있으면
슬랙에 올려 주세요 — 그건 여러분 잘못이 아니라 배포본의 결함입니다.

## 왜 이렇게 하나요

남의 코드베이스에 내 코드를 붙이는 일은 실무에서 계속 하게 됩니다. 그때 사고가 나는 이유는 대부분 "남의 코드를 조금 고쳤는데 다른 데가 깨져서"입니다.

본체를 안 건드리면 이 사고가 구조적으로 안 납니다. 대신 **접점을 미리 정해두고 그것만 씁니다.** 10주차에 배우는 Block 출력 계약과 같은 발상입니다. 그때는 데이터의 모양을 고정했고, 여기서는 코드가 만나는 지점을 고정합니다.

## 본체와 만나는 곳은 셋뿐입니다

여러분이 만든 부품과 본체가 **닿는 자리**를 접점이라고 부릅니다.
집에 있는 **콘센트**와 같습니다. 벽 안의 전선을 뜯지 않아도, 콘센트에 꽂기만 하면
새 가전이 돌아갑니다. 콘센트 모양이 정해져 있으니 아무 가전이나 꽂을 수 있고,
고장이 나도 벽이 아니라 그 가전만 확인하면 됩니다.

브레인의 콘센트는 셋입니다.

| 접점(콘센트) | 방향 | 언제 씁니다 |
|---|---|---|
| `raw/` | 쓰기 | 검문을 통과한 문서를 넣을 때 |
| `wiki/` | 읽기 | 정리된 지식을 검색하거나 인용할 때 |
| `scripts/lib/llm_client.call_llm` | 호출 | LLM 이 필요할 때 |

이식 ⑥(14주차)에서 `review/` 쓰기가 하나 더 붙습니다. 게이트를 통과 못 한 문서를 넣어 두는 검수함입니다.

이 셋 말고 본체의 다른 함수를 직접 부르지 않습니다. 접점이 셋이면 무엇이 깨질 수 있는지도 셋뿐입니다.

## 파일 하나의 기본 골격

```python
"""w10_vision_ingest.py — 사진·PDF·HTML을 검문한 뒤 raw/에 넣는다.

사용: python extensions/w10_vision_ingest.py ~/사진/화이트보드.jpg
본체 수정 0줄. 접점은 raw/ 에 md 를 쓰는 것 하나뿐.
"""
import os
import sys

# 본체의 scripts/ 를 import 할 수 있게 경로를 잡아 준다
sys.path.insert(0, os.path.join(os.path.dirname(os.path.dirname(os.path.abspath(__file__))), "scripts"))

BRAIN_HOME = os.environ.get("BRAIN_HOME", os.path.dirname(os.path.dirname(os.path.abspath(__file__))))
```

맨 위 세 줄짜리 설명에 **무엇을 하는지, 어떻게 실행하는지, 어느 접점을 쓰는지**를 적습니다. 3주 뒤의 내가 읽습니다.

## 8주 동안 여기에 쌓이는 것

| 주차 | 파일 | 브레인의 무엇이 되나 |
|---|---|---|
| 10 | `w10_vision_ingest.py` | 눈 — 사진·PDF가 들어오면 데이터가 된다 |
| 11 | `w11_embed_search.py` | 의미 기억 — 흐릿한 질문으로도 찾아진다 |
| 11 | `w11_watch.py` | 아침마다 스스로 자료를 먹는다 |
| 12 | `w12_answer_card.py` | 입 — 출처를 달고 답한다 |
| 13 | `w13_brain_mcp.py` | 손 — 다른 AI가 내 브레인에게 물어본다 |
| 14 | `w14_graph_runner.py` | 신경계 — 흐름이 그래프로 보인다 |

> 파일 이름에 붙은 **`mcp`** 는 Model Context Protocol 의 약자입니다.
> 말이 어렵지만 뜻은 간단합니다. **AI 끼리 대화하는 공통 규격**입니다.
> USB 단자가 정해져 있어서 어느 회사 기기든 꽂히는 것과 같습니다.
> 13주차에 이걸 붙이면 ChatGPT 나 Claude 같은 다른 AI 가
> 내 브레인에게 "그 자료 뭐였지?" 하고 물어볼 수 있게 됩니다.

여섯 개 중 다섯 개는 수업 노트북이 파일을 만들어 주고, 여러분은 그걸 여기로 옮깁니다. `w11_embed_search.py` 하나만 직접 작성하는 도전과제입니다.

## 하나가 막혀도 다음 주는 진행됩니다

**각 이식은 앞의 이식에 의존하지 않습니다.** 10주차 눈을 못 달았어도 11주차 의미 기억은 붙습니다. 막힌 주가 있으면 **공용 시드**로 대체 제출하고 다음으로 갑니다.

> **시드(seed)** 는 "씨앗"이라는 뜻으로, 강사가 미리 넣어 둔 **연습용 자료**를 말합니다.
> `examples/seed-raw/` 에 있습니다. 요리 실습에서 재료를 못 챙겨 온 사람에게
> 학원이 재료를 빌려주는 것과 같습니다. 실습은 할 수 있지만,
> 집에 가져갈 반찬은 내 재료로 만든 것뿐입니다.

다만 시드로도 돌아가긴 하지만 **좋은 결과는 내 위키에서만 나옵니다.** "지난달에 비슷한 고민 적었던 것"은 남의 시드에 없습니다. 그래서 각 실습에 `시드 위키 vs 내 위키` 비교가 들어 있습니다.
