# 메모 — 내 PM 도구 스택

지금 쓰는 도구 정리. 각자 역할.

## 도구
- **Notion** — 문서·PRD·회의록·위키. 팀 지식의 단일 출처(SoT).
- **Figma** — 와이어프레임·프로토타입. 디자이너와 협업, 솔루션 빠르게 그려보기.
- **Linear** — 이슈·스프린트 트래킹. RICE **우선순위** 점수를 이슈에 적어둔다.
- **Amplitude** — 제품 분석. **리텐션** 코호트·퍼널·A/B 결과를 본다.

## 패턴
- 디스커버리 결론(인터뷰·**JTBD**) → Notion **PRD** → Linear 이슈 → Amplitude로 결과 측정.
- 즉 도구가 "문제 → 결정 → 실행 → 측정"의 한 바퀴를 받친다.

## 주의
- 도구를 늘리지 말 것. 같은 정보를 여러 곳에 두면 SoT가 깨진다.
