# Hermes 연결 검증 범위

2026-10-10 코드 기준입니다. 점수와 코드 공개가 운영 환경 실행을 대신하지 않습니다.

## 확인한 것

- 통합 setup 기본 실행은 미리보기이며 설정과 Brain 파일을 변경하지 않습니다.
- 승인한 설정 파일에 조회와 관리 MCP, 통합 `/llm-brain` 스킬 하나를 등록합니다. 기존 Mem0, 모델, 다른 MCP와 동일 Brain 조회 런타임을 보존합니다. 기존 `/llm-brain-manage` 설치본은 변경하지 않습니다.
- 동일 등록을 다시 실행하면 설정과 백업을 바꾸지 않습니다. 다른 기존 연결, 사용자 지정 스킬, 링크 경로와 백업 충돌은 변경 전에 거절합니다.
- `--migrate-public-skill`과 `--apply`로 명시 승인한 경우만 알려진 이전 공개 조회 스킬 fingerprint를 백업 후 갱신합니다. 기본 실행은 이전 스킬 충돌도 거절합니다. 사용자 수정본은 마이그레이션 옵션으로도 변경하지 않습니다.
- 등록된 command, args, cwd로 실제 stdio MCP를 시작하고 가상 메모 저장, 한 건 RULE 정리, audit와 별도 읽기 세션의 재조회 및 출처 일치를 확인했습니다.
- LIVE는 기본 허용하지 않습니다. 선택 원본과 다른 출처의 모델 응답은 저장 전에 거절해 RULE로 대체합니다. 선택 메모 정리에는 전체 목차를 전송하지 않습니다.
- 통합 스킬 수정본의 fresh 독립 교육 R2 92점, 기술 R2 96점입니다. 평가 점수는 아래 모델 실행 결과와 별개입니다.

## 실행한 명령

```bash
.venv/bin/python -m pytest tests/test_hermes_bundle_setup.py -q
.venv/bin/python -m pytest -q
```

이전 공개 버전은 통합 12 passed, 전체 875 passed와 7 skipped였습니다. 현재 통합 스킬 및 설치 변경 후 관련 26 passed, 전체 883 passed와 7 skipped입니다. 최소 RED는 canonical 설치와 기존 호환 스킬 보존, 명시적인 migration 인자 부재로 3 failed였으며 구현 뒤 통과했습니다. 기본 audit 회귀도 수정 전 페이지 변경을 재현하고 수정 후 보존을 확인했습니다. 기존 의존성을 사용했으며 새 환경 설치 검증이 아닙니다.

## 실제 모델과 실패 기록

- 격리 홈과 가상 업무 메모에서 `nvidia/nemotron-3.5-lightning:free`로 통합 스킬 저장, 지정 note_id RULE 정리, 반환 slug 재조회, 품질 보고서 생성을 실제 실행했습니다.
- 새 대화 재사용은 첫 실행의 150초 timeout, 두 번째 실행의 JSON 오류/추측 slug/혼합 언어와 exit1을 기록했습니다. 도구 발견과 업무 검색의 query를 구분하도록 스킬을 보강한 최종 세 번째 실행은 검색, 실제 읽기, 한국어 양식과 출처 확인 후 exit0이었습니다. 공급자 스트림 오류 후 런타임 재시도가 있었으며 반복 안정성을 보장하는 결과는 아닙니다.
- 단일 요청 CLI가 slash 문자를 자동 처리한다고 가정하지 않고 Hermes 실제 CLI/Gateway의 스킬 메시지 생성 함수를 사용했습니다. 실제 Slack 화면 검증은 아닙니다.
- 독립 Codex CLI는 정상 sandbox에서 모델/MCP 시작 전 app-server `Operation not permitted (os error 1)`, exit1로 차단됐습니다. Codex 자연어 E2E는 미검증이며 권한을 우회하지 않았습니다.
- Hermes 대화 모델은 호출했고 Brain LIVE 정리 모델은 호출하지 않았습니다. 운영 프로필과 사용자 자료는 변경하지 않았습니다.

전체 검사에서 내부 docs 기록의 공개 경계 위반이 발견됐습니다. 해당 기록은 로컬에 보존하고 공개 추적에서 제외한 후 전체 검사를 다시 실행해 통과했습니다. 사용자 자료와 운영 프로필은 변경하지 않았습니다.

## 별도 확인이 필요한 것

- 실제 유료 LIVE와 요약 내용의 정확성
- 다른 모델에서의 스킬 준수와 반복 실행 안정성, Codex CLI 자연어 전체 흐름
- 실제 운영 프로필의 설정 반영과 Slack 요청, 응답, 출처 확인
- 새 가상환경 설치와 Windows 실기기 실행
