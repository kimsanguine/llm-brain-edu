# Hermes 연결 검증 범위

2026-10-10 코드 기준입니다. 점수와 코드 공개가 운영 환경 실행을 대신하지 않습니다.

## 확인한 것

- 통합 setup 기본 실행은 미리보기이며 설정과 Brain 파일을 변경하지 않습니다.
- 승인한 설정 파일에 조회와 관리 MCP, 두 스킬을 등록합니다. 기존 Mem0, 모델, 다른 MCP와 동일 Brain 조회 런타임을 보존합니다.
- 동일 등록을 다시 실행하면 설정과 백업을 바꾸지 않습니다. 다른 기존 연결, 사용자 지정 스킬, 링크 경로와 백업 충돌은 변경 전에 거절합니다.
- 등록된 command, args, cwd로 실제 stdio MCP를 시작하고 가상 메모 저장, 한 건 RULE 정리, audit와 별도 읽기 세션의 재조회 및 출처 일치를 확인했습니다.
- LIVE는 기본 허용하지 않습니다. 선택 원본과 다른 출처의 모델 응답은 저장 전에 거절해 RULE로 대체합니다. 선택 메모 정리에는 전체 목차를 전송하지 않습니다.
- 독립 교육 96점, 기술 95점. 기술 2차에서 도움말과 실제 등록 설정의 종단 간 테스트를 재확인했습니다.

.venv/bin/python -m pytest tests/test_hermes_bundle_setup.py -q

전체 검사에서 내부 docs 기록의 공개 경계 위반이 발견됐습니다. 해당 기록은 로컬에 보존하고 공개 추적에서 제외한 후 전체 검사를 다시 실행해 통과했습니다. 사용자 자료와 운영 프로필은 변경하지 않았습니다.
